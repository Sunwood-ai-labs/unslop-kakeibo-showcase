## Live Interactive Showcase

All four household ledger concepts run directly in your browser with zero external runtime dependencies. Each app shares the same October 2026 household ledger dataset (`¥284,620` monthly spend across 5 envelopes) and supports live transaction entry (`[N]`), instant redline X-Ray (`[U]`), AI slop comparison (`[B]`), and theme switching (`[T]`).

| ID | Concept | Character & Material World | Live Application |
| :--- | :--- | :--- | :--- |
| **`00`** | **Masu (枡)** | `calm, exact, tactile` — Quiet Graphite (`#141415`), brushed metal cards, thermal receipt, and 5-envelope mirrored spline curves. | [Open 00 Masu ↗](/unslop-kakeibo-showcase/demo/index.html){target="_blank"} |
| **`01`** | **Kakei Shiori (家計栞)** | `warm, literary, unhurried` — Warm Archival Paper (`#f7f4ee`), brass clip botanical voucher, and single-highlighted October bar chart. | [Open 01 Shiori ↗](/unslop-kakeibo-showcase/demo/concepts/shiori/index.html){target="_blank"} |
| **`02`** | **Pulse (パルス)** | `technical, high-precision, atmospheric` — Deep Ink (`#0a0b0d`), oscilloscope glyph, split-flap counter, and 31-day signal orange impulse bars. | [Open 02 Pulse ↗](/unslop-kakeibo-showcase/demo/concepts/pulse/index.html){target="_blank"} |
| **`03`** | **Tokonoma (床の間)** | `architectural, serene, structural` — Alabaster 1px Swiss Grid (`#f4f3ef`), monumental serif numerals with vermilion seal (`済`), and floor-plan treemap. | [Open 03 Tokonoma ↗](/unslop-kakeibo-showcase/demo/concepts/tokonoma/index.html){target="_blank"} |
