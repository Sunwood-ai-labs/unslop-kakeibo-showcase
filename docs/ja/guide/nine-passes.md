# 9つの赤入れPassと「引き算」の知見

## 9つのPass（9 Redline Passes）実装チェックリスト

**[unslop](https://heydamir.design/unslop)** メソドロジーでは、「5行のDirection」を固定した後に9段階の赤入れ工程（Passes）を順番に適用します。本ショーケースの4つの家計簿アプリすべてに適用されている実装規律は以下の通りです。

| Pass | 領域 | AIスロップの典型例（禁止事項） | 本ショーケースで徹底した規律 |
| :--- | :--- | :--- | :--- |
| **Pass 1** | **Spacing（余白）** | 場当たり的なピクセル値（`13px`, `27px`）、窮屈なカード内余白、不揃いな間隔。 | すべての余白・サイズを `4px` グリッド（`4, 8, 12, 16, 20, 24, 28, 32, 40, 48px`）で統一。`00 枡` ではサイドバー幅 `256px`（内余白 `16px`、行高 `34px`、行間 `2px`、見出し上 `24px` / 下 `8px`）、トップバー高 `56px`、カード内パディング `20px 24px`。 |
| **Pass 2** | **Color（色彩）** | 紫〜シアンのグラデーション、光る枠線、画面中に散らばる原色バッジ。 | UIクロームは徹底した無彩色（Dark: `#0f0f10`〜`#232325`、Light: `#f2efe9`〜`#fdfbf7`）。色彩は「2つのMoments」と費目を示す `6px` ドットのみに限定。プライマリボタンはオフホワイト（`#ededed`）または墨色（`#1c1b18`）。 |
| **Pass 3** | **Icons（アイコン）** | ナビや費目見出しへの絵文字乱用（`🏠`, `🍔`, `💰`, `✨`）、線の太さがバラバラなアイコン。 | 通常モードにおける**絵文字の完全排除（0個）**。すべて `16px`・`stroke-width="1.5"` の単色インライン SVG で統一し、親要素の文字色（`currentColor`）を継承。 |
| **Pass 4** | **Copy（文言）** | 過剰な挨拶（`おかえりなさい!! 👋`）、比較対象のわからない増減率（`-8.4%` のみ）、煽り文句。 | 期間コンテキスト（`2026年 10月`）を明確な見出しに設定。すべての変化率に比較基準を等幅フォントで併記（`前月比 -8.4%`、`目標差 +¥24,380`）。 |
| **Pass 5** | **Type（文字組）** | 極太ウェイト（`700`〜`900`）の多用、意味のない大文字トラッキング、桁がガタつくプロポーショナル数字。 | フォントウェイトは `400` と `500` のみ（`700` 以上は禁止）。すべての金額・日付・割合・件数に `'JetBrains Mono'` と `font-variant-numeric: tabular-nums`（等幅数字）を強制。 |
| **Pass 6** | **Layout（骨格）** | 同じサイズの統計カード4枚を均等配置して主役が不在になるレイアウト。 | フルハイトのデスクトップ骨格（左 `256px` 固定サイドバーまたは `56px` アイコンレール＋最大 `1440px` メイン領域）。上段の非対称サマリ、中段 `2:1` のチャート＆費目列、下段の明細テーブル＋右証憑インスペクタ。 |
| **Pass 7** | **Details（細部）** | 外枠と内枠で同じ角丸半径を使う違和感、統計カード内の装飾用ミニスパークライン。 | 同心円状の Nested Radius（キーキャップ `4px`、ボタン・ナビ行 `8px`、カード `12px`、モーダル `16px`）。統計カード内の不要なミニスパークラインを完全撤去。 |
| **Pass 8** | **Visuals（視覚要素）** | 抽象的な3Dブロブや意味のない装飾イラスト、画面内で競合する複数の派手なグラフ。 | 視覚的な密度と色彩を **Moment 1**（決済カード＆感熱レシート / 銅版画証憑 / オシロスコープ / 朱印）と **Moment 2**（メインチャート）の2箇所のみに集中。 |
| **Pass 9** | **Motion（動き）** | バウンスするアニメーション、常時脈動するドット、ホバー時のカード拡大（`hover:scale`）。 | ループアニメーションやホバー拡大を全廃。単一のイージング曲線 `cubic-bezier(0.22, 1, 0.36, 1)` による背景・境界線・不透明度の静かな遷移のみを実装。 |

## 検証から得られた核心的知見：「引き算」と100%日本語UI化

4つのコンセプトを実装・視覚検証する過程で、初期の9 Passes適用後にもまだ残っていた「もっともらしいノイズ（デザイナーズ・スロップ）」が浮き彫りになりました。それが **「不要な日英併記ラベル」** と **「雰囲気だけの疑似コード・メタバッジ」** です。

### 1. 日英二重表記（バイリンガル・スロップ）の撤去

日本語のWebアプリをAIに作らせると、「洗練された雰囲気」を出そうとして、すべての見出しやラベルに英語と日本語を併記する癖があります（例: `Spent this month · 今月の支出`、`Overview · 概要`、`OCTOBER 2026 · 2026年10月`）。しかし実際の道具として毎日使う家計簿において、同じ意味の言葉を2言語で繰り返すのは視覚ノイズでしかありません。

| UIパーツ | 引き算前（日英併記のノイズが残る状態） | 引き算後（100%自然な日本語UI） |
| :--- | :--- | :--- |
| **ブランド表記** | `Masu 枡 — HOUSEHOLD LEDGER` | `枡` |
| **左ナビゲーション** | `Overview · 概要`, `Transactions · 明細`, `Envelopes · 予算` | `概要`, `明細台帳`, `予算の枡`, `カード・口座` |
| **主要統計カード** | `SPENT THIS MONTH · 今月の支出` | `今月の支出` |
| **前月比較ラベル** | `-8.4% vs Sep 2026 (¥310,720)` | `前月比 -8.4%` / `9月実績 ¥310,720` |
| **上部ユーティリティ** | `Unslop X-Ray [U]`, `Compare Slop [B]`, `Theme [T]` | `赤入れ検証 [U]`, `スロップ比較 [B]`, `配色 [T]` |

### 2. 雰囲気だけの「図面番号・シリアルコード」の排除

`01 家計栞` や `02 パルス`、`03 床の間` のような世界観の強いUIでは、初期段階で `FOLIO NO. 2026-10` や `SYS-TELEMETRY // 02`、`FIG. 01 — MADORI ALLOCATION` といった「それっぽい英語の図面コード」を添えてしまいがちです。

しかし **Pass 4（Copy）** と **Pass 7（Details）** の観点で厳しく見直すと、日々の食費や住居費を確認するユーザーにとって、意味を持たない装飾用の管理番号は本来の「金額」から視線を奪うノイズです。これらをすべて削ぎ落とし、簡潔な日本語見出しと等幅の金額数字だけを残した瞬間、4つの世界観それぞれの物質感（黒鉛、コットン紙、オシロスコープ、漆喰と1px罫線）がより純粋に立ち上がりました。

### 3. メソドロジー自己主張バッジの「赤入れ検証モード `[U]`」への隔離

デザイン検証用のショーケースを作るときに陥りやすいもうひとつの罠が、通常画面のヘッダーやフッターに `UNSLOP 9 PASSES VERIFIED` や `4PX GRID SYSTEM` といった「ルール適用の自己宣伝バッジ」を常時表示してしまうことです。

- **通常モード**: 設計手法の名前やルール説明を一切表示せず、純粋な「日本の家計台帳」として静かに機能する。
- **赤入れ検証モード（`[U]`）**: <kbd>U</kbd> キーを押したときだけ、`data-xray` 属性による赤入れラベルと検証バナーが出現し、どの要素にどのPassが効いているかを解説する。

この分離によって、「実用の道具としての静けさ」と「設計ショーケースとしての解説性」を両立させています。

## ライブ画面で体験するビフォー・アフター（`[B]` キー）

これらの引き算がどれほど画面の明快さを変えるかは、各ライブアプリを開いて <kbd>B</kbd> キー（**スロップ比較**）を押すことで即座に体験できます。

1. **[00 枡 (Masu) ライブデモ ↗](/unslop-kakeibo-showcase/demo/index.html){target="_blank"}** — <kbd>B</kbd> キーで、静謐なグラファイト台帳が「紫グラデーション＋絵文字ラベル＋煽りコピー」の典型的なAIダッシュボードへ変貌します。
2. **[01 家計栞 (Shiori) ライブデモ ↗](/unslop-kakeibo-showcase/demo/concepts/shiori/index.html){target="_blank"}** — <kbd>B</kbd> キーで、コットン紙の帳面とネオン装飾カードの差を比較できます。
3. **[02 パルス (Pulse) ライブデモ ↗](/unslop-kakeibo-showcase/demo/concepts/pulse/index.html){target="_blank"}** — <kbd>B</kbd> キーで、単一シグナルオレンジの計測器UIと多色グラデーションUIの差を比較できます。
4. **[03 床の間 (Tokonoma) ライブデモ ↗](/unslop-kakeibo-showcase/demo/concepts/tokonoma/index.html){target="_blank"}** — <kbd>B</kbd> キーで、1px露出スイスグリッドと浮遊する角丸シャドウカードの差を比較できます。
