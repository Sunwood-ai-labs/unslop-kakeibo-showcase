# 概要と5行のDirection

## 本ショーケースの目的

AIに「家計簿アプリ」や「支出ダッシュボード」のUI生成を指示すると、ほぼ例外なく典型的な **「AIスロップ（AI Slop）」** に収束します。紫からシアンへ光るグラデーション背景、浮遊するガラスモーフィズムのカード、絵文字だらけの費目ラベル（`🏠 住居費`、`🍔 食費`）、極太（`700〜900`）の見出し、感嘆符付きの挨拶（`おかえりなさい!! 👋`）、そしてすべての統計カードに無意味に添えられたミニスパークラインです。

本リポジトリは、**[Damir Sokolovsky (@heydamir)](https://x.com/heydamir)** 氏が公開したUI設計スキル **[unslop](https://heydamir.design/unslop)**（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）の有効性を検証するため、その2大原則を日本語の家計簿アプリケーションに厳格に適用したショーケースです。

1. **5行の Direction（Five-Line Direction）**: コードを1行書く前に、プロダクトの定義・3つの性格形容詞・物質的な世界観・画面内2箇所限定の視覚的見せ場（Moments）・一貫したシグネチャを固定する。
2. **9つの赤入れ Pass（9 Redline Passes）**: 余白・色彩・アイコン・文言・タイポグラフィ・レイアウト・ディテール・ビジュアル・モーションの9工程でノイズを引き算し、静かで精確な道具へと磨き上げる。

> [!IMPORTANT]
> `unslop` が単なる「黒っぽいミニマル風テーマ」ではないことを実証するため、まったく同じ家計データと9つのPassの上に、**4つの異なる物質的世界観**（`00 枡`、`01 家計栞`、`02 パルス`、`03 床の間`）を構築しています。

## 「5行のDirection」とは何か？

レイアウトやカラーコードを決める前に、`unslop` では以下の **5行の Direction** を言語化します。

| 行 | 定義項目 | なぜ AI スロップを防げるのか |
| :--- | :--- | :--- |
| **1. Product** | 誰のための、何をする道具かを1文で定義する。 | 機能の肥大化を防ぎ、すべての画面を「家計の把握と記帳」という本質に集中させる。 |
| **2. Character** | 性格を表す3つの形容詞（例: `calm, exact, tactile`）。 | 余白の広さ、境界線の強さ、コントラストの判断に一貫した審美フィルターを与える。 |
| **3. World** | UIが参照する現実世界の物質・道具・空間。 | 凡庸なSaaSテンプレートを脱し、黒鉛・コットン紙・オシロスコープ・漆喰といった手触りを宿す。 |
| **4. Moments** | 画面内で色彩と造形密度を高める箇所を**最大2箇所**に絞る。 | 要素同士の主役争いを防ぐ。すべてが目立つ画面では、結果として何も目立たなくなる。 |
| **5. Signature** | 画面全体に控えめに反復される構造的モチーフ。 | 派手なブランドカラーや巨大ロゴに頼らず、道具としての統一感を生み出す。 |

## 共通データセットとインタラクティブ機能

4つのアプリはすべて2026年10月の同一家計簿データを参照し、新規記帳データはブラウザの `LocalStorage` に保存されます。

- **月次収入**: `¥420,000`
- **当月支出（2026年10月）**: `¥284,620`（前月9月 `¥310,720` 比 `-8.4%`）
- **月次予算枠**: `¥310,000`（予算残高 `¥25,380`）
- **5つの予算費目（Envelopes）**:
  1. 住居・固定費 — `¥118,000 / ¥120,000`
  2. 食費・日用品 — `¥68,420 / ¥75,000`
  3. 交際・文化 — `¥44,800 / ¥45,000`
  4. 交通・移動 — `¥21,400 / ¥30,000`
  5. 特別・予備 — `¥32,000 / ¥40,000`

### 共通キーボードショートカット

どのコンセプトのライブ画面でも、以下のショートカットキー（または上部バーのボタン）で検証機能を即座に切り替えられます。

| キー | 機能名 | 動作内容 |
| :---: | :--- | :--- |
| <kbd>U</kbd> | **赤入れ検証 (Unslop X-Ray)** | 画面上の各要素に、9つのPass（4pxグリッド、無彩色クローム、等幅数字、2つのMoments等）のどこが効いているかを赤色のガイド枠とラベルでオーバーレイ表示します。 |
| <kbd>B</kbd> | **スロップ比較 (Compare Slop)** | 同じ家計データを、典型的なAI生成テンプレート（紫ネオングラデーション、絵文字ラベル、煽り文句、過剰なドロップシャドウ）で表示した状態へ即座に切り替え、引き算の効果を比較できます。 |
| <kbd>T</kbd> | **配色切替 (Theme Switch)** | ダークモード（Quiet Graphite / Deep Ink）とライトモード（Warm Paper / Alabaster）を切り替えます。 |
| <kbd>N</kbd> | **新規記帳モーダル** | 新しい支出明細を追加し、上段の統計値・Moment 2のチャート・費目バー・明細一覧をリアルタイムに再計算します。 |
| <kbd>/</kbd> または <kbd>⌘K</kbd> | **明細検索** | 店名・摘要・費目・決済手段で明細テーブルを即座にフィルタリングします。 |
| <kbd>1</kbd> – <kbd>4</kbd> | **サブビュー切替** | 概要 / 明細・日次推移 / 予算費目 / カード・設計仕様の各サブビューを切り替えます。 |
